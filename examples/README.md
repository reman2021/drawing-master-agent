> 简介：可在 Excalidraw、Mermaid 和 draw.io 兼容编辑器中继续编辑的生成示例。

## 示例

- `login-flow.excalidraw`、`login-flow.mmd`、`login-flow.drawio`：同一核心流程图的三种语义等价格式产物。
- `microservice-architecture.excalidraw`：带系统分区的核心架构图示例。

示例分别由 [`fixtures/specs/flowchart.json`](../fixtures/specs/flowchart.json) 和 [`fixtures/specs/architecture.json`](../fixtures/specs/architecture.json) 通过项目运行时生成。Mermaid 文件是纯源码，draw.io 文件是未压缩单页 XML。

Excalidraw 和 draw.io 示例使用当前排版基线：节点 `24px`、边标签 `18px`。Mermaid 的字号和形状尺寸由打开文件的渲染器主题决定。
