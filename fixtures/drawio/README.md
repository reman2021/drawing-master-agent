> 简介：Drawing Master 未压缩单页 draw.io XML 的代表性格式快照。

## 约定

- `.drawio` 使用 `compressed="false"` 的 `mxfile`。
- 每个文件只包含一个 `diagram` 和一个 `mxGraphModel`。
- `mxfile` 保存文档身份、规格哈希和运行时版本。
- 禁止 `DOCTYPE`、脚本、HTML 标签和主动链接。
- 节点、边、注释和分区标题必须显式保存字号，不得依赖 diagrams.net 默认字体。
- 发布前需在 diagrams.net 中进行人工打开检查。
