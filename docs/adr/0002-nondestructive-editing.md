## 背景

用户会在 Excalidraw 中手工调整布局、颜色和内容，也可能要求修改不是本 Agent 创建的文档。整体重绘虽然容易保持统一风格，却会破坏手工元素、未知字段和用户调整。

## 决策

采用非破坏性原位修改：只修改用户明确指定的目标，默认保留已有位置、尺寸、样式、未知字段和未知元素。

系统使用文档身份、DiagramSpec 中的语义 ID、元素 `customData` 和清单索引建立稳定映射。修改前创建备份；目标不明确时必须询问，不猜测。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 每次整体重绘 | 布局统一，但容易造成大量无关变更和信息丢失。 |
| 只修改本系统生成的图 | 实现简单，但不符合修改外部图表的目标。 |
| 仅依赖元素 ID | 不需要附加元数据，但复制、导入和重建后映射不稳定。 |

## 影响

- 用户手工编辑得到保护，版本差异更小。
- 需要宽容解析、字段透传、备份和语义身份映射。
- 某些外部元素无法安全修改时必须拒绝目标变更，而不是整体覆盖。
