## 背景

绘图大师需要在任意项目中可用。项目本地脚本无法被全局 Agent 稳定定位；与此同时，本机 skill 加载器当前因 PowerShell Archive 模块问题无法加载技能包，因此不能作为必需运行路径。

## 决策

采用全局自包含 Agent 与独立运行时：Agent 安装到 `~/.config/opencode/agents/`，运行时安装到 `~/.config/opencode/drawing-master/`。

Agent 提示词包含完成任务所需的核心规范，不要求调用 skill 工具。项目仓库是 Agent、运行时、测试和安装脚本的版本化来源。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 依赖全局 skill | 结构清晰，但受当前加载器故障阻断。 |
| 每个目标项目复制运行时 | 项目自足，但会产生重复文件和版本漂移。 |
| 发布全局 npm CLI | 安装体验好，但引入包发布和版本维护成本。 |

## 影响

- Agent 不受 skill 加载器可用性影响。
- 安装脚本必须同步 Agent 和运行时，并处理升级。
- 全局配置更新后需要重启或重新加载 opencode 才能发现 Agent。
